SpeakiRPG

Settings apply instantly, no restart needed

Account

Sign out of the game site session and return to the login screen so you can sign in with a different account. Clears game cookies and site storage; client settings and mods are kept. Restricted or banned accounts stay restricted after logout.

Chat translation

Source language is detected automatically (Korean, Japanese, English, ...). Translated text replaces the line, the original stays in brackets.

Translation API

Raises the free MyMemory quota when set. Each user uses their own limit.

Same unofficial endpoint as the Chrome translate widget. Can rate-limit (HTTP 429); switch back to MyMemory or Custom if that happens.

Placeholders: {text}, {target}, {source}, {api_key}. Leave POST body empty for GET. Plain-text responses work without JSON path. Ollama + Qwen3: add "think":false at the top level of the JSON (see docs).

Developer

Advanced modding only. Patches the game bundle on load; may break after a game update. Reload the game (F5) after toggling.

Mod settings

Enable a mod with a settings schema to see options here.

Mods

Small scripts that hook chat, stats, and translation. See docs/mods.md for the API and how the client reads the game page.
